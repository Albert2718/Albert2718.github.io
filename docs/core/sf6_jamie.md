# 街霸6213小时终上大师 ＆ 个人杰米常用压制思路 

格斗萌新街霸6213小时终于拿到了第一个master！

回想去年年底刚上铂金和钻石，本以为大师触手可及，谁知真正的磨炼才刚刚开始。那时的我只会无脑绿冲嘟嘟嘟和偶尔偷个迸发和点辰，杰米许多拳脚和必杀完全不用。现在回头看，感慨万千。

格斗游戏带来的挫败感很强烈，训练场里只有你和木桩，连段掉招谁都怪不了；比赛中只有你和对手，很多时候对方明明并不厉害，只会复读一两招，却依然能够轻松地战胜那个在训练场泡了一晚上，看了很多教学的你，这种挫败感和红温曾一度让我想放弃这个游戏，卖掉眼前的hitbox，选择一些更放松的活动，平日里看看比赛过过格斗瘾就好。

但同时，格斗游戏也有着无与伦比、无可替代的正反馈：萌新阶段搓出个必杀到打出一套完美的连段带来的成就感，随着水平的提升，每当你的知识量增加并付诸实践时，每当你在关键时刻凭本能做出了最优的选择时，我慢慢明白了为什么有那么多人喜欢这个游戏，格斗游戏是一场超越自己的修行，它让你直面真实的自己，在这里，天赋或许能决定起点，但只有纯粹的热爱与坚持才能决定你最终能否走下去。

借着上大师的契机，分享一些杰米的压制与立回心得，欢迎大家指正和补充，也希望有大佬可以讲讲大师后如何继续提升！

## 一些简写说明:
1. 方向拳脚简写：数字（1~9）+ l/m/h + p/k:
   可以把1-9看作一个数字键盘到方向的映射，1是下后，2是下（蹲），5是站立，6是前，4是后等等；l(light)是轻，m(medium)是中，h(heavy)是重：p(punch)是拳，k(kick)是脚; 例如2hp就是蹲重拳，44就是后后。
2. 帧数简写：f
   frame，指的是游戏中的帧数；帧数是格斗游戏计量时间的单位，在街霸6中每秒有60帧。

## 压制相关
杰米哥的压制能力很强，现在我喝到第一口酒后基本就不会放弃压制来喝酒了，对于杰米哥，进攻是最好的防守。杰米哥的许多压制都是基于+42f，+39f的情况，分别介绍；

**+42f：**
轻升龙，轻爆回，重推掌后都是+42f（除了一些浮空的特殊情况，比如说板边od推 + 嘟嘟嘟 + 轻升龙是+39f）。 

**在版中**，我们可以两个前前来进行压制，一个前前是19f，所以两个前前过后我们有利4f，我们可以选择投 / 轻攻击2lk打下段 + 2lp / 轻攻击2lp连点 or 点投/ 后后打拆 / 拉蹲防防凹 / 5mp站中拳压起身（打防+2f，打中+6f）

轻攻击2lp打中+5f，两点确认到打中后我们可以接tc，tc后可以接轻升龙 / 轻爆回继续保持+42f的压制；

值得一提的是5mp的压起身，对方如果起身抢4f的轻攻击会和5mp相杀，但此时仍然是我们先行动并且有利更多帧数，确认能力好的可以接2hp+后续继续压制，或者直接接tc / 目押2mp接后续：靠近板边我比较喜欢选择后者，因为2mp后可以接od推掌，od推掌在版边有很多后续，在能打出更高伤害的同时也可以保持压制。

如果对手喜欢拆投，44后我们可以接5mk + 重推掌/重爆回（确反康才可以接）或者直接5mk绿冲取消后随便接（梦幻连 or 5mp + 2hp + 任意必杀等等）继续保持压制，但后后会被对面抢招打到 or 凹到，建议观察到对方喜欢延迟拆的习惯后使用。


**在板边**，+42f意味着我们可以进行安全跳，安全跳顾名思义就是不会被对空技打中的跳，除此之外，我们可以在空中进行跳攻击的同时防凹，跳攻击打防也是我们有利，保持压制。

在必杀结束后我们按住前和跳，跳起来后再拉后，下落时跳攻击。落地后同样选择很多：投 / 轻攻击2lk打下段 + 2lp / 轻攻击2lp连点 or 点投/ 后后打拆 / 拉蹲防防凹 / 5mp站中拳，对面如果喜欢乱动就有福了，我们同样用+42f来收尾，继续安全跳压制。

如果对方很稳健的话，我们可以空中不进行任何动作，落地投 / 点辰 / 偷下段，但这三者均会被对方抢招打到，建议观察对方习惯后再使用。

此外，如果板边想点辰压起身的话，前前的+4f会被对方抢到，因为点辰8f发生且同帧打大于投技，建议距离允许的情况下用2hp卡帧，此时+7f, 会输给凹、跳和后后，但不会被抢到

**+39f：**
重升龙、中推掌以及很多浮空后嘟嘟嘟接升龙（前面说的板边od推 + 嘟嘟嘟 + 轻升龙，sa3后续的前前嘟嘟嘟取消升龙等等）都是+39f。

版中+39f的前前压制力一般，两个前前只+1f，投会被对方最速4f轻攻击打到，所以建议轻攻击连点推开距离or最后一下复合流醉拳，很多时候这个距离很陷阱，这个时候尝试打对面的差合或者直接自动驾驶一个5hk，很多时候能打到对面的收招。很多高手基本上都会选择一个前前后交绿冲压制。

板边+39f的压制力很强，我们可以普通投卡帧（从鬼马GM那里学到的），此时+9f，我们最速5mp可以偷到2帧，最终+4f，可以继续按5mp（不会被抢，最次也是相杀可以接）+ 2mk，此时距离同样暧昧，尝试差合对面。除此之外可以2hp卡帧后+4f压制 or 嘟嘟嘟卡帧后+5f可点辰压起身。

## 立回相关：

怎么喝到第一口酒：推掌摸奖，凹升龙（我比较建议第一次凹在对手的加帧后凹，比如绿冲后的拳脚以及加帧技or加帧拳脚，倒地有时候对面会延迟压），开局抓习惯：对方喜欢直跳就前跳 + 跳重脚截空 +（嘟嘟嘟 +）下重脚派生喝酒；
对方喜欢后跳或者后后就直接喝，除此之外就要在立回中找到机会了：

2mk：杰米哥的下中脚现在十分好用，发生快，距离远，可以直接取消绿冲，打中后梦幻连喝酒 or 其他连段均可，或者复合轻中流醉形成暧昧距离，这个需要对距离有一定的把控。值得一提的是，EVO评的最佳拳脚是肯的2mk，和现在杰米哥的2mk都是7f发生，距离也一样（甚至好像杰米哥更长一点点），所以真的很强。

绿冲嘟嘟嘟：嘟嘟嘟作为5f发生的重拳且本身带有前位移，加上绿冲很快很难截，而且总帧数长容易确认，打中接轻攻击连段，黄康可以2mp接后续，红康（确反康）可以2hp接后续，打防+1f, 想投需要前走。

空箭：神技，拿轻空箭骗升龙一骗一个不吱声，空箭插到脚趾可以加帧，打点太高会被确反，但od空箭不会，且打中可以接后续：版中放帧下重脚派生喝酒，板边嘟嘟嘟 + 下重脚派生喝酒；两种情况也可直接接ca。

跳逆：轻的就跳轻拳落地轻攻击，建议用跳中脚，落地可以5mp + 2mp。

关于一酒tc：不是很喜欢用，更多是作为确认后的连段组件，因为1酒tc如果打防想要安全只能绿冲取消轻攻击打联防，否则很容易被对面复合凹稳定对策（不过如果发现对方这个习惯就可以进一步博弈 用取消迸发来赢对面的复合凹）
